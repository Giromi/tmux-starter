# tmux-starter

터미널 하나 안에서 **화면을 여러 칸으로 나누고, 창(탭)을 여러 개 만들고, 터미널을 닫아도 작업을 살려 두는** 프로그램 [tmux](https://github.com/tmux/tmux)의 시작용 설정 파일입니다.
파일은 `tmux.conf` 하나뿐이고, 주석이 모두 한국어로 달려 있어서 열어 보고 마음대로 고칠 수 있습니다.

이런 분께 맞습니다.

- tmux 를 처음 써 보는데 기본 설정이 불편한 분
- 단축키 몇 개만 외워서 바로 쓰고 싶은 분
- 복잡한 플러그인 없이 가볍게 시작하고 싶은 분

## 설치

tmux 3.2 이상이 필요합니다. 터미널에 아래 명령을 한 줄씩 붙여 넣으세요.

**1) tmux 설치** (이미 있으면 건너뛰세요. 확인: `tmux -V`)

```
brew install tmux
```

리눅스(Ubuntu 등)는 이렇게 합니다.

```
sudo apt install tmux
```

**2) 지금 쓰던 설정이 있으면 백업**

```
[ -f ~/.tmux.conf ] && cp ~/.tmux.conf ~/.tmux.conf.backup
```

**3) 설정 파일 내려받기**

```
curl -fsSL https://raw.githubusercontent.com/Giromi/tmux-starter/main/tmux.conf -o ~/.tmux.conf
```

**4) 시작**

```
tmux
```

이미 tmux 가 켜져 있었다면, tmux 안에서 `Ctrl+t`를 누르고 손을 뗀 다음 `r`을 누르면 새 설정이 적용됩니다.

## 알아 둘 것: 접두 키(prefix)

tmux 의 단축키는 **먼저 접두 키를 누르고, 손을 완전히 뗀 다음, 다음 키를 누르는** 방식입니다.
이 설정에서 접두 키는 `Ctrl+t`입니다. (원래 기본값은 `Ctrl+b`)

아래 표에서 `접두 키 → |`는 "`Ctrl+t`를 눌렀다 떼고, `|`를 누른다"는 뜻입니다.

## 키 표

| 키 | 동작 |
| --- | --- |
| `접두 키 → ?` | 단축키 목록 보기 (`q`로 닫기) |
| `접두 키 → r` | 설정 파일 다시 읽기 |
| `접두 키 → \|` | 화면을 **좌우**로 나누기 |
| `접두 키 → _` | 화면을 **위아래**로 나누기 |
| `접두 키 → h` `j` `k` `l` | 왼쪽 / 아래 / 위 / 오른쪽 칸으로 이동 |
| `접두 키 → w` | 방금 있던 칸으로 돌아가기 |
| `접두 키 → Ctrl+방향키` | 칸 크기 조절 (누른 채로 반복 가능) |
| `접두 키 → H` `J` `K` `L` | 칸 크기 조절 (`Shift`+글자, 맥에서 Ctrl+방향키가 안 먹을 때) |
| `접두 키 → c` | 새 창(탭) 만들기 |
| `접두 키 → 0`~`9` | 그 번호의 창으로 이동 (번호는 1부터 시작) |
| `접두 키 → n` / `p` | 다음 창 / 이전 창 |
| `접두 키 → t` 또는 `접두 키 → Ctrl+t` | 방금 있던 창으로 돌아가기 |
| `접두 키 → ,` | 지금 창 이름 바꾸기 |
| `접두 키 → $` | 지금 세션 이름 바꾸기 |
| `접두 키 → s` | 세션 목록에서 고르기 |
| `접두 키 → d` | tmux 에서 빠져나오기 (작업은 계속 돌아갑니다. 다시 들어가려면 `tmux attach`) |
| `접두 키 → x` | 지금 칸 닫기 (확인 질문이 나옵니다) |
| `접두 키 → z` | 지금 칸을 화면 가득 키우기 / 되돌리기 |
| `접두 키 → [` | 복사 모드 시작 (아래 설명) |
| `접두 키 → S` | **모든 칸에 동시에 입력**하기 켜기/끄기 (켤 때 한 번 물어봅니다. 켜져 있으면 왼쪽 아래에 빨간 표시, 칸 테두리도 빨개집니다) |

### 마우스

켜져 있습니다. 칸을 클릭하면 이동하고, 경계선을 끌면 크기가 바뀌고, 휠로 위로 스크롤할 수 있고, 글자를 드래그하면 복사됩니다.

### 복사 모드

1. `접두 키 → [` 로 들어갑니다.
2. 화살표 키나 `h` `j` `k` `l` 로 움직이고, `v` 로 선택을 시작합니다.
3. `y` 를 누르면 복사되고 나옵니다. (`q` 만 누르면 복사 없이 나옵니다)

붙여 넣기는 `접두 키 → ]` 입니다. 사용하는 터미널에 따라 시스템 클립보드로 바로 복사되지 않을 수 있는데, 그때는 `tmux.conf` 안의 `pbcopy`(맥) 또는 `xclip`(리눅스) 줄의 맨 앞 `#` 을 지우세요.

## 커스터마이즈

`~/.tmux.conf` 를 열어서 고친 뒤 `접두 키 → r` 을 누르면 바로 적용됩니다. 주석을 읽으면서 아래 줄들만 바꿔 보세요.

- **접두 키 바꾸기**: `set -g prefix C-t` 와 `unbind C-b` 줄. `C-t` 를 `C-a` 처럼 바꾸면 됩니다. 아래의 `bind ... C-t last-window` 줄도 같이 바꾸세요.
- **마우스 끄기**: `set -g mouse on` 을 `off` 로.
- **창 번호를 0부터**: `base-index 1` 과 `pane-base-index 1` 을 `0` 으로.
- **색 바꾸기**: `colour235` 같은 숫자는 0~255 사이의 터미널 색 번호입니다. 상태 줄은 `status-style`, 칸 경계선은 `pane-active-border-style` 줄입니다.
- **단축키 추가**: `bind <키> <동작>` 한 줄을 더하면 됩니다. 예: `bind a new-window`

## 플러그인 (선택 사항, 몰라도 됩니다)

`tmux.conf` 맨 아래에 주석 처리된 플러그인 구역이 있습니다. 쓰고 싶을 때만 켜세요.

1. 플러그인 관리자 내려받기
   ```
   git clone https://github.com/tmux-plugins/tpm ~/.tmux/plugins/tpm
   ```
2. `~/.tmux.conf` 맨 아래 "플러그인" 구역의 `#` 을 지웁니다. (`run` 줄은 파일의 맨 마지막에 있어야 합니다)
3. tmux 안에서 `접두 키 → Shift+i` 를 누르면 설치됩니다.

넣어 둔 플러그인은 `tmux-sensible`(무난한 기본값)과 `tmux-resurrect`(`접두 키 → Ctrl+s` 로 창 배치 저장, `접두 키 → Ctrl+r` 로 복원)입니다.

## 문제가 생기면

- **`unknown option` 같은 오류가 뜬다**: `tmux -V` 로 버전을 확인하세요. 3.2 보다 낮으면 업그레이드가 필요합니다.
- **한글이 깨진다**: 터미널 설정에서 문자 인코딩이 UTF-8 인지 확인하세요.
- **설정이 안 바뀐다**: `접두 키 → r` 을 눌렀는지, 그래도 안 되면 `tmux kill-server` 로 tmux 를 완전히 끄고 다시 `tmux` 를 실행해 보세요. (열어 둔 작업은 모두 닫힙니다)

## 제거

원래 쓰던 설정으로 되돌립니다.

```
[ -f ~/.tmux.conf.backup ] && mv ~/.tmux.conf.backup ~/.tmux.conf || rm ~/.tmux.conf
```

플러그인 구역을 켰었다면 이것도 지우세요.

```
rm -rf ~/.tmux/plugins
```

tmux 자체를 지우려면 `brew uninstall tmux` (맥) 또는 `sudo apt remove tmux` (리눅스) 입니다.
